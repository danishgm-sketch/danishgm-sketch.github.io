Data sources · source-registry-1.1.0

Official source register

This page records the four official series MGI uses. It shows what each series measures, how MGI retrieves it, what reuse is allowed and when the source must be reviewed.

How to read this page

Why these sources are listed

Naming a source lets you check the figure and its definition. No source endorsement is claimed: the Bank of England and ONS do not endorse MGI. Their data does not become investment advice when it appears here.

How live checks are protected

MGI accepts data only from registered addresses and formats

A live check must use HTTPS, the registered website address and the expected file format. It stops after 10 seconds and rejects redirects or oversized responses. A temporary network error gets one retry. After that, only the affected figure uses its verified saved copy or becomes unavailable.

Error records use a random reference number. They do not store web addresses, query values, credentials or response bodies.

Quality notes

  • One quarterly estimate does not represent GDP per head, household welfare or the full path of demand.

How source files are stored

A private local archive stores approved files with checksums, source details, parser details and licence rules. It currently holds the four checked fallback files. It does not yet capture every live response, use production cloud storage or offer public downloads. Full revision history remains future work.
