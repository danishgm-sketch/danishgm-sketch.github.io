    Known limitations

    • The interface redesign does not add a new economic source, observation or calculation.

    • The registered public snapshot covers release 0.6.15; earlier Market Pulse releases do not yet have equivalent full manifests.
    • No production PostgreSQL service is provisioned or connected; the public site reads the checked repository snapshot.
    • The public repository holds the checked release currently used by each indicator, not a complete run of earlier official vintages.
    • MGI does not call a current figure unrevised when it lacks an earlier comparable release.
    • Future official revisions are not ingested or archived automatically.
    • The archive currently uses the local filesystem for development and tests; no production object-storage provider is provisioned or connected.
    • The archive command stores the four checked fallback files. Automatic capture of every live source response is not yet scheduled.
    • The ONS CSV fallback files are labelled as verified fallbacks, not as raw upstream JSON responses.
    • The archive is private and has no public download route.
    • The custom domains are founder-owned but DNS, HTTPS and the .com route-preserving redirect have not been configured or verified.
    • The legal operator, suitable public service address and branded email are not yet established for broad commercial promotion.
    • The governance pages remain implementation drafts and have not received specialist UK financial-services, privacy or consumer-law review.
    • General contact and correction submissions require a GitHub account and are public.
    • MGI has no private support inbox; privacy requests requiring personal details begin with a minimal public request for a private reply route.
    • The live official endpoints can fail validation; MGI then exposes a verified repository fallback or withholds only the affected state.
    • Quarter-on-quarter GDP is quarterly, rounded to one decimal place and subject to later revision.
    • The partial policy model still lacks connected policy-transmission data.
    • The open 30 July 2026 forecast remains unresolved until authoritative outcome evidence is available.
    • MGI remains a research and education product, not investment advice or a trading signal.
