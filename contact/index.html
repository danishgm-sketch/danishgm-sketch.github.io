Everything in an issue is public

Do not post passwords, account details, identity documents, private financial information, health information or confidential material. For a privacy request, post only that you need a private reply route—not the private details themselves.

Security reports

Do not disclose a suspected vulnerability in a public issue. Use the private GitHub security-advisory route instead.
